# ADR-0004 · Sheet vs Modal: capa flotante según contexto

**Estado:** Aceptado.

## Contexto

Emet necesita superficies de edición/acción (adjuntar, reenviar, cámara, formularios de solicitud). Las opciones eran modal clásico, drawer lateral o bottom-sheet.

## Decisión

Se usa el componente **`Sheet`** como capa flotante única de contexto, con comportamiento adaptativo:

- **Desktop**: centrado (dialog).
- **Mobile**: desliza desde abajo (nativo).

La edición de formularios largos (solicitudes, alta de empleado) usa Sheet reutilizado entre pantallas con el mismo orden de campos. `Dialog` existe en el kit para confirmaciones ligeras que no requieren el contexto completo de un Sheet.

## Consecuencias

- Un solo patrón mental para "abrir detalle/acción": menos ambigüedad de UI.
- El Sheet se porta al body y usa el tema global (incluso dentro del scope chat).
- Foco atrapado + `Escape` cierra (a11y, ver `ACCESSIBILITY.md`).
