# ADR-0011 · Pickers nativos (sin datepicker de terceros)

**Estado:** Aceptado.

## Contexto

El sistema necesita fechas, horas, colores y rangos en varios formularios. Las librerías de datepicker pesan, estilizan mal en móvil y añaden deuda.

## Decisión

**Nativos estilizados** o el kit propio: `input[type=date/time/datetime-local/color/range]`, `SlidingSegments` para elecciones discretas, `Menu`/`Sheet` para listas contextuales. El calendario de equipo usa el motor propio (ver `modules/CALENDAR.md`).

## Consecuencias

- En móvil se abre el picker del SO (mejor UX nativa, cero librería).
- En desktop se estiliza el control del sistema.
- Las fechas se muestran SIEMPRE en formato legible; el valor guardado es ISO.
- Ver `docs/design/PICKERS.md`, `docs/coding/AI_RULES.md` (no introducir librerías sin validar).
