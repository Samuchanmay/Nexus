# ADR-0009 · Server-Side Rendering con Next.js App Router

**Estado:** Aceptado.

## Contexto

Emet necesita autenticación por cookies, listas iniciales rápidas, SEO básico y una experiencia SPA para el chat.

## Decisión

**Next.js 15 (App Router) + React 19** con patrón SSR: Server Components por defecto, `"use client"` solo donde hay interactividad, Supabase con cookies (`@supabase/ssr` 0.5.2) y `updateSession` en middleware.

## Consecuencias

- Las listas iniciales llegan sin flash de carga; la interacción se hidrata.
- Las rutas se protegen en servidor/middleware, no solo en el cliente.
- El chat usa client components pesados (realtime, drag, swipe) bajo páginas ligeras.
- Ver `docs/architecture/ARCHITECTURE.md`, `docs/coding/REACT.md`.
