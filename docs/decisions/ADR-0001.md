# ADR-0001 · El chat es un módulo del sistema, no una app aparte

**Estado:** Aceptado · **Fecha:** establecida con el diseño del chat.

## Contexto

El chat nació con estética propia (workspace tipo Linear/Discord/Slack) y tecnología propia. Cabía la tentación de tratarlo como producto independiente (app aparte, login propio).

## Decisión

El chat es un **módulo de Emet**: mismo login, mismo tema, mismas sesiones, misma base de datos. Comparte el design system global (tokens) dentro de un scope propio `.chat-ws` que remapea los tokens para el modo "premium", pero no duplica identidad: mismo acento azul, misma familia de iconos, mismas reglas de accesibilidad.

## Consecuencias

- Una sola sesión sirve para fichar, ver vacaciones y chatear.
- El chat reusa `Sheet`, `Avatar`, `Toast`, el pipeline de imágenes y las Edge Functions del sistema.
- El scope `.chat-ws` limita el riesgo de fuga de estilos al resto de la app.
- Ver `docs/modules/CHAT.md`.
