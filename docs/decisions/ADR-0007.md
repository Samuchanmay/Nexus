# ADR-0007 · RDBMS gestionada con Supabase (Postgres)

**Estado:** Aceptado.

## Contexto

Se necesitaba DB con auth, RLS, Realtime, Storage y Edge Functions integrados, para una app de tamaño mediano sin equipo de infra.

## Decisión

**Supabase (Postgres)** como plataforma: Postgres (schema en `supabase/schema.sql`, migraciones 0002–0024), Auth (SSR con `@supabase/ssr`), Realtime (chat), Storage privado (`chat-files`) y Edge Functions en Deno (12).

## Consecuencias

- Menos infra que administrar; RLS nativo; Realtime para chat sin websockets propios.
- Vendor lock moderado: las migraciones SQL son portables; las Edge Functions de negocio son Deno estándar.
- La lógica de negocio vive en la DB (triggers/RPC `nx_*`) — ver ADR-0005.
- Ver `docs/coding/SUPABASE.md`.
