# ADR-0015 · Rebrand: Nexus → Emet

**Estado:** Aceptado · **Aplicado:** commit `be31144`.

## Contexto

El sistema se conocía como "Nexus". Se decidió renombrar la identidad a **Emet** manteniendo intacta la arquitectura.

## Decisión

Rebrand de **marca visible y nombres de código** (rutas, comentarios, Edge Functions, README, package.json), con alcance documentado:

- **Sí cambió**: nombre de app, rutas visibles (`/admin/nexus` → `/admin/asistencia`), comentarios en `src/` y `supabase/`, cabeceras de Edge Functions, README (ahora apunta a `docs/00-README.md`).
- **No cambió (deuda registrada en `DECISIONES-PENDIENTES.md`)**: columnas `nexus_clave`/`nexus_color`, dominios legacy `nexus-*.vercel.app` en middleware/`ALLOWED_ORIGINS`, claves localStorage `nexus-*`, dominio de correo `nexus@cert.edu.mx`, prefijo de RPC `nx_*`.

## Consecuencias

- La identidad visible es 100% Emet; el build verifica la ruta nueva (`/admin/asistencia`).
- El renombrado de deuda se hace con migración/plan (P-005…P-007), no "sobre la marcha".
- Regla para agentes: no introducir nuevos usos de "Nexus" ni "nx_" en código visible nuevo; la deuda existente se limpia en su propia tarea.
- Ver `docs/DECISIONES-PENDIENTES.md`, `docs/coding/NAMING.md`.
