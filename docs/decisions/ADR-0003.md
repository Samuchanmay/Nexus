# ADR-0003 · MFA obligatorio para admin y rh

**Estado:** Aceptado.

## Contexto

Emet maneja datos sensibles: saldos, nóminas implícitas, historial del equipo, archivos privados. Los roles `admin` y `rh` tienen acceso amplio vía RLS.

## Decisión

**MFA TOTP obligatorio** para `admin` y `rh`; opcional para el resto. Si un admin/rh inicia sesión sin TOTP enrolado, se le redirige a `/mfa/*` a enrolar antes de operar.

## Consecuencias

- Reduce el riesgo de sesión comprometida en roles con datos amplios.
- Añade un paso en el onboarding de estos roles (ver `modules/ONBOARDING.md`).
- El chequeo se hace en el flujo de sesión/guard de rutas (`src/lib/nav.ts` + middleware), no solo en UI.
