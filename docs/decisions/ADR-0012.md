# ADR-0012 · Pipeline de imágenes en storage privado (bucket chat-files)

**Estado:** Aceptado.

## Contexto

El chat y las evidencias de recorridos manejan imágenes de tamaño arbitrario (cámara, adjuntos). Servirlas al original es lento y caro; guardarlas en un bucket público expone privacidad.

## Decisión

- **Bucket `chat-files` privado** (migración 0024) con pipeline WebP: `thumb` (~200px), `medium` (~1000px) y `original`.
- El cliente pide la variante adecuada (`SmartImage` según viewport).
- Acceso por **URL firmada / `proxy-asset`**, nunca público.
- `drive-upload` reusa el pipeline para evidencias de recorridos.

## Consecuencias

- Velocidad (variantes pequeñas para listas) y privacidad (bucket privado).
- Almacenamiento eficiente (WebP).
- Regla: los archivos nuevos del sistema pasan por este pipeline; no subir originales crudos a buckets públicos.
- Ver `docs/modules/CHAT.md`, `docs/modules/RECORRIDOS.md`.
