# ADR-0014 · Exportación de reportes con ExcelJS (y PDF por print CSS)

**Estado:** Aceptado.

## Contexto

Los reportes (asistencia semanal, saldos) se consumen en pantalla y también se comparten fuera de Emet (jefatura, expedientes).

## Decisión

- **Excel** con **exceljs 4.4.0** (generación server-side/Edge, formato de celda, estilos y tipado de filas).
- **PDF** mediante **print CSS** (`@media print`): `break-inside: avoid`, colores en grises legibles — sin librería de PDF extra.

## Consecuencias

- Una sola fuente de datos (DB/vistas/RPC) para pantalla y exportación; lo que ves es lo que exportas.
- Menos dependencias (sin generador de PDF).
- La Edge `weekly-attendance-report` calcula/envía el reporte semanal.
- Ver `docs/modules/REPORTS.md`, `docs/design/TABLES.md`.
